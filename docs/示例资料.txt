公司内部本地私有知识库及智能办公助手项目说明

一、项目目标
本项目的目标是在公司局域网内部署一个本地私有知识库及智能办公助手。
员工可以通过它查询公司制度、流程、常见问题和内部资料。
系统必须优先使用公司本地资料回答问题，不能依赖云端 API。

二、第一阶段范围
第一阶段只完成单机版 RAG 跑通。
也就是说，先使用 Python 脚本读取本地文档，把文档切分成知识片段，再通过本地向量库检索相关内容，最后调用局域网 Ollama 上的 deepseek-r1:14b 模型回答问题。
第一阶段暂时不做网页界面，不做用户登录，不做部门权限隔离，也不引入 LangGraph。

三、后续演进方向
第二阶段会升级到 LangGraph 状态机，引入上下文压缩和部门隔离逻辑。
第三阶段会引入 Flask 后端和 HTML 前端，让公司员工通过浏览器访问。

四、本地化要求
系统必须 100% 纯本地运行。
大语言模型使用公司局域网 Ollama 服务。
向量库使用本地轻量方案，不能使用第三方云端向量数据库。
